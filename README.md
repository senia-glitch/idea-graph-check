# Проверка графа

Пакет-скилл с кодом. Код мгновенно находит сирот, круги в связях, одинаковые заголовки, непринятые
карточки и допущения, от которых зависит много карточек. Агент ищет противоречия, дубли по смыслу,
расплывчатые формулировки и пробелы и по каждой находке задаёт вопрос.

Находки — карточки «замечание» уровней «мешает» и «заметка». Итог работы («чисто» или
«есть_мешающие») считает код. После первой полной проверки проверяется только изменённое.

## Установка

```
pip install -e .
```

Нужны `ideagraph-core` и `ideagraph-shell`.

## Тесты

```
pip install pytest
python -m pytest
```
